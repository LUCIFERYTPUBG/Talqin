# TALQIN

TALQIN — talabalarga mo‘ljallangan jonli ovozli darslar, Zakovat va bilim almashish platformasi.

## Texnologiyalar
- React
- Vite
- Lucide React

## Lokal ishga tushirish
```bash
npm install
npm run dev
```

## Render Static Site
- Build Command: `npm install && npm run build`
- Publish Directory: `dist`

> Hozirgi versiya — interaktiv frontend prototip. Haqiqiy WebRTC audio xonalari, autentifikatsiya, backend va ko‘p ishtirokchili Zakovat hali ulanmagan.
